# Règles Absolues NODE (Source de Vérité)

## 1. Alignement Fixe Absolu
- Tous les éléments de la sidebar `.left` (Titre NODE, Boutons, "VUE GRAPHIQUE") doivent partager la **même ligne de départ virtuelle à gauche**.
- **Interdiction de marges ou paddings cumulatifs** : Le conteneur du Header (`#command-center-header`) ne doit **pas** ajouter de `padding-left` supplémentaire s'il hérite déjà du padding global de `.left`. 
- **Verrouillage Flexbox** : Les conteneurs Flex entourant le Titre ou les Boutons générés par `quartz.layout` ont tendance à se centrer horizontalement (`justify-self: center`). Ils doivent impérativement être écrasés par `align-self: flex-start !important` pour garantir un alignement à gauche de marbre.

## 2. Header Binaire (Fin de l'Interpolation)
- L'animation du header ne repose plus sur une interpolation fluide CSS calculée à chaque pixel.
- Le système bascule rigoureusement sur un **état binaire** : passé un défilement de **60px**, le Javascript injecte la classe `.is-shrunk` au conteneur du header. C'est cette classe qui pilote toutes les réductions de taille via des transitions CSS natives (ex: `transition: height 0.3s ease`).

## 3. États du Titre NODE
- **État Normal (sans `.is-shrunk`)** : Taille de police à **5.5rem**.
- **État Réduit (avec `.is-shrunk`)** : Taille de police à **3rem**.

## 4. Chorégraphie Compacte
- En version réduite (`.is-shrunk`), les 3 boutons d'action (Loupe, DarkMode, Reader) glissent vers le haut (`translateY`) pour se placer **strictement sous** le titre NODE.
- Ils **ne doivent jamais** recourir à des translations horizontales (`translateX`) lors du scroll : leur axe X est sanctuarisé.
- L'icône de recherche se compresse dynamiquement via la réduction de son `max-width` sans décaler son point d'origine à gauche.
- **Pureté de l'icône Recherche** : En version compacte, le conteneur de recherche doit être vierge (aucun fond, aucune bordure, aucun `box-shadow`) pour flotter gracieusement dans le noir. En version normale (`4rem`), la largeur de la recherche est plafonnée à `180px` pour garantir que l'icône Reader la plus à droite ne soit jamais tronquée.
- Le "bouclier" noir doit s'adapter mathématiquement pour héberger le titre réduit et les boutons (hauteur fixée à `115px`). Il est soumis à une `transition: height 0.3s ease`.

## 5. Physique et Rythme de la Sidebar
- **Éradication du Conteneur Fantôme** : Lors du passage en état réduit (`.is-shrunk`), le conteneur principal du header doit **réellement** réduire sa hauteur DOM (de `200px` à `115px`).
- **Graphe Toujours Visible** : Le graphe est **toujours affiché** sous son titre VUE GRAPHIQUE. Il n'y a pas de chevron, pas de toggle, pas de `collapsed`. Le graphe défile naturellement avec le reste de la sidebar.
- **Pas de Sticky** : Le titre et le graphe utilisent un `position: relative` standard. Aucun `position: sticky` ne doit être appliqué sur le graphe ou son titre.
- **Gravité Flex Descendante** : La sidebar `.left` et le conteneur du graphe utilisent `flex-direction: column` + `justify-content: flex-start`. Tout pousse vers le bas.
- **Rythme Visuel des Icônes** : `gap: 1.2rem` + `padding-right: 1.5rem` minimum pour protéger l'icône Reader.

## 6. Table des Matières (TOC) & Scroll Spy
- **Design "Gutter Glide"** : Tous les indicateurs visuels (barres verticales) doivent être alignés à l'extrême gauche du conteneur parent, ignorant l'indentation du texte pour une structure verticale rigoureuse.
- **Teinte "Soft Tertiary Tint"** : La zone de lecture active (`is-active`) ne doit pas utiliser de barres fantômes mais une simple coloration du texte via `var(--tertiary)` à 100% d'opacité.
- **Focus Actif** : Seul le titre focal (`active`) bénéficie du **gras**, d'une **barre pleine** et d'un **fond vitre à 9%**.
- **Synchronisation Multi-TOC** : Le script `toc.inline.ts` doit impérativement utiliser une logique basée sur les `slugs` pour synchroniser en temps réel le bureau et le menu mobile.
- **Scroll Offset** : Une marge `scroll-margin-top: 5rem` est obligatoire sur tous les titres (`h1-h6`) pour garantir un atterrissage élégant sous le header et une détection fiable par le Scroll Spy.

## 7. Outils et Validation
- Toujours utiliser l'agent navigateur (Puppeteer) pour valider visuellement *et* mathématiquement le `z-index`, la progression de `.left`, et la position horizontale (axe X) des boutons avant de confirmer toute modification de layout.
