# Règles Absolues NODE (Source de Vérité pour les Agents) 🛡️💎🌀

Ce document régit l'intégrité visuelle et technique du projet Quartz "NODE". Tout agent intervenant doit s'y conformer pour ne pas briser l'esthétique "Premium Documentation" établie.

---

## 🏗️ 1. Architecture du Layout & Alignement
- **Axe X Sanctuarisé** : Tous les éléments de la sidebar `.left` (Titre, Boutons, Explorer, Graphe) partagent la **même ligne de départ virtuelle à gauche**. Aucun padding-left cumulatif ne doit être ajouté au Header s'il hérite déjà du conteneur parent.
- **Header Binaire** : L'animation du header est pilotée par la classe `.is-shrunk` (injectée via JS à 60px de scroll).
- **Métriques du Header (Desktop)** :
    - **Normal** : Hauteur conteneur **170px**, Bouclier opaque (`::before`) **155px**.
    - **Réduit (`.is-shrunk`)** : Hauteur conteneur **110px**, Bouclier opaque **110px**.
- **Chorégraphie des Boutons** : En mode réduit, les icônes (Recherche, Dark, Reader) glissent vers le haut (`translateY(-38px)`) pour s'aligner sous le titre NODE. **Interdiction de translation horizontale (Axe X)**.

## 🔗 2. Esthétique des Liens (Transitions Fluides)
- **Soulignement Permanent** : Les liens ont **toujours** `text-decoration: underline`.
- **Fondu Stoppé** : Au repos, `text-decoration-color` est `transparent`. Au survol, elle passe à la couleur accentuée.
- **Timing Staggered** : 
    - Couleur du texte : **0.35s ease**.
    - Couleur du soulignement : **0.5s ease** (plus lent pour un effet "infusion").
- **Interdiction** : Ne jamais utiliser de pseudo-éléments `::after` pour le soulignement manuel (conflits de layout).

## 🧱 3. Contenu Rédactionnel (H1-H2)
- **Spécifications des Titres** :
    - **H1** : Souligné (`border-bottom`) avec `var(--secondary)` (3px).
    - **H2** : Souligné (`border-bottom`) avec `var(--secondary)` (2px).
    - **Style** : Aucun fond coloré, aucun glass-morphism.
- **Titre NODE & Menu** : Doivent rester vierges de tout fond coloré ou glass-morphism.

## 📱 4. Mobile & Navigation
- **Menu Mobile** : Les icônes Loupe et Reader Mode sont côte à côte. Les bordures de titres utilisent `currentColor`.
- **Reader Mode** : Cycle à 3 états (Normal -> Light -> Full) sur Desktop, 2 états sur Mobile. Persistance via `localStorage`.

## 🗺️ 5. Footer & Nomenclature
- **Modernité** : Utiliser impérativement "**mail**" au lieu de "**Email**".
- **Responsive** : Une seule ligne sur Desktop avec séparateur bullet. Stack vertical automatique sur Mobile/Ecran étroit.

## 🛠️ 6. Gestion du Contenu & Build
- **Jonction Locale** : Le dossier `content` à la racine est une **Jonction de Répertoire** pointant vers `D:/Utilisateur/Documents/Sonorisation`. Ne jamais le remplacer par un fichier texte.
- **Synchronisation GitHub** : Pour que GitHub Actions puisse builder le site, les fichiers `.md` doivent être **physiquement copiés** dans `content` avant le `push`. Utiliser le script `robocopy` dédié pour automatiser le cycle :
    1. Backup v4 -> Copie Physique -> Git Push v4.
    2. Merge v1 -> Git Push v1.
    3. Rétablissement Jonction sur v4.

---

## 🚦 7. Validation Obligatoire
Avant toute livraison : 
1. Vérifier que le titre **NODE** ne bave pas lors du scroll.
2. Vérifier que le soulignement des liens est fluide (pas d'apparition instantanée).
3. Vérifier le build via `npx quartz build`.
