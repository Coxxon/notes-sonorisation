# VLAN  

**Partition logique d'un réseau local physique.**  

Un VLAN permet de segmenter un switch unique en plusieurs réseaux virtuels isolés.  
Les appareils d'un VLAN ne peuvent pas communiquer avec ceux d'un autre VLAN, même s'ils sont branchés sur le même switch.  
Les VLANs permettent de séparer les flux de données en utilisant une seule infrastructure réseau physique.
