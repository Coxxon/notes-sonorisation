# Trunk  

**Lien physique transportant plusieurs VLANs simultanément.**  

Un port en mode Trunk est configuré pour laisser passer les trames de plusieurs VLANs entre deux switches.  
Pour que le switch voisin sache à quel VLAN appartient chaque trame, il utilise un tag propre à chaque VLAN.
