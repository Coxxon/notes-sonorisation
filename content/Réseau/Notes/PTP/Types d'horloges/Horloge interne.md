# Horloge interne  

**Oscillateur matériel (quartz) propre à chaque appareil.**  

L'objectif du [[Precision Time Protocol (PTP)|PTP]] est de dicter le rythme à l'horloge interne pour qu'elle accélère ou ralentisse (algorithme PLL) afin de rester parfaitement [[Synchronisation|synchronisée]] avec le reste du réseau.
