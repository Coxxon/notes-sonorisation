# Types d'horloges PTP

Cette section documente les différents types d'horloges utilisés dans le protocole PTP.

## Types principaux

### Horloge de référence
- **Fonction** : Fournit une référence de temps précise
- **Utilisation** : Synchronisation des autres horloges du réseau

### Horloge d'écoute
- **Fonction** : Écoute les messages PTP
- **Utilisation** : Coordination des échanges temporels

### Horloge de bordure
- **Fonction** : Définit les limites temporelles du réseau
- **Utilisation** : Contraintes de synchronisation
