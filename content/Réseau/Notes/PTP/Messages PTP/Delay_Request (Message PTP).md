# Delay_Request (Message PTP)

**Message envoyé par la [[Follower Clock]] à la [[Master Clock]] en mode [[End-to-End (E2E)|End-to-End]] en [[Precision Time Protocol (PTP)|PTP]].**  

- Les [[Follower Clock|Follower Clocks]] envoient périodiquement une demande de délai à leur [[Master Clock]].  
- Le message est horodaté au moment où le message quitte l'horloge émettrice.
