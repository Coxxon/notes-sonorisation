# Pdelay_Request (Message PTP)

**Message envoyé par deux voisins directs en mode [[Peer-to-Peer (P2P)|Peer-to-Peer]] uniquement.**

- Ce message est envoyé par un appareil à son voisin direct, **dans les deux sens**, pour mesurer le délai de propagation dans le [[Segment|segment]] qui les relie.  
- Ce message ne traverse jamais les switches.
