# Root Guard  

Sécurité **[[Spanning Tree Protocol (STP) et Rapid-STP (RSTP)|Spanning Tree]]**.

**Empêche un switch branché sur le port de devenir [[Root Bridge]].**
Si un switch plus prioritaire est branché sur un port protégé, ce dernier se coupe pour protéger la hiérarchie en place.
