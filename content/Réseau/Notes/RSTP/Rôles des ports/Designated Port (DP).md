# Designated Port (DP)  

**Le port en amont d'une liaison entre deux switches.**
Sur chaque liaison entre deux switches, celui qui est le plus proche de la racine possède le Designated Port.

- **Fonction :** Transmet les données utilisateur et les [[BPDU (Bridge Protocol Data Unit)|BPDU]] vers l'aval (vers les autres switches ou appareils).
- **Note :** Tous les ports actifs du **[[Root Bridge]]** sont des DP.
