# Topologie  

Structure **du réseau**.  

Organisation des connexions entre les switches.  
Elle est soit : 
- **Physique** : désigne les appareils et câbles branchés  
- **Logique** : désigne les chemins autorisés par le [[Spanning Tree Protocol (STP) et Rapid-STP (RSTP)|Spanning Tree]] pour éviter les boucles
