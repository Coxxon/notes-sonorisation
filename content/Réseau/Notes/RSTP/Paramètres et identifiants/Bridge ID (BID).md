# Bridge ID (BID)  

**Identifiant unique d'un switch dans le réseau.**  

**Bridge ID = [[Bridge Priority]] (0 - 61 440) + [[Adresse MAC]]**

- **Règle :** Plus le BID est bas, plus le switch est prioritaire.
- **Usage :** Sert de critère principal pour l'élection du **[[Root Bridge]]**
