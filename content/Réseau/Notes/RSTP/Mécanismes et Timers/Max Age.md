# Max Age  

Durée de vie d'un message [[BPDU (Bridge Protocol Data Unit)|BPDU]].

Durée (20s par défaut) pendant laquelle un switch conserve les informations d'un [[BPDU (Bridge Protocol Data Unit)|BPDU]].  
Si aucun nouveau message n'est reçu passé ce délai, le switch considère que le chemin est tombé.
